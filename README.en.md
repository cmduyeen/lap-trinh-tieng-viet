A free, open-source suite of Vietnamese CLI tools and learning aids designed to help **Vietnamese beginners, students, and kids** learn Terminal, Python, Git, and GitHub without English barriers — while gradually bridging them to standard international commands.

## ✨ Highlights

- **Beginner-Friendly Vietnamese Commands:** Short, easy-to-remember Vietnamese commands and localized error explanations.
- **Bridge Mode Learning:** Shows the underlying standard commands (`git`, `gh`, PowerShell, `.py`) so learners naturally transition to industry-standard workflows.
- **Safety-First Defaults:** Recycle Bin deletion, non-overwriting file operations, and explicit confirmations.
- **1-Line Windows All-in-One Installer:** Install all tools at once, 100% free under MIT License.

## ⚡ 1-Line Install (Windows PowerShell)

```powershell
irm https://raw.githubusercontent.com/cmduyeen/lap-trinh-tieng-viet/main/install.ps1 | iex
```
